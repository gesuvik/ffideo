# FFideo 1.0.0 — changelog

> Public bootstrap beta. This build is ad-hoc signed, not notarized, and published with explicit Gatekeeper instructions.

## Added

- Reproducible arm64 FFmpeg 9.0.2/FFprobe toolchain built under LGPL terms.
- Dynamically linked, replaceable LAME 3.100 library.
- Six conversion recipes backed by one declarative catalog.
- Media probing and output validation before final commit.
- Five-successful-export evaluation domain and testable licensing boundary.
- Fail-closed release, compliance, checksum, and production gates.

## Security and reliability

- Direct process launch without a shell.
- Canonical bundle-only helpers, bounded logs, process-group cancellation, and cleanup.
- Network protocols disabled in the shipped FFmpeg build.
- No overwrite of source or existing output files.

## Distribution status

This public bootstrap beta is available for Apple Silicon Macs running macOS 13 or later. It is ad-hoc signed and not notarized, so the first launch may require an explicit approval through Finder or System Settings. The site presents the US$4.99 one-time FFideo Pro offer and five-export evaluation, but checkout stays disabled until the verified Lemon Squeezy public URL is configured. The post-purchase page documents manual license-key activation without claiming account, webhook, or key-import automation.
