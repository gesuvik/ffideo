Bootstrap release disclosure

Not notarized. Install deliberately.

The current artifact is ad-hoc signed and not notarized. macOS may require an explicit exception for the first launch. Do not disable Gatekeeper globally.

  1. Verify SHA256SUMS supplied with the release.
  2. Extract FFideo-1.0.0.zip.
  3. Move FFideo.app to Applications.
  4. Launch it. If macOS blocks it, open System Settings → Privacy & Security → Open Anyway.
