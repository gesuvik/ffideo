FFideo 1.0.0 · release candidate

Install FFideo

The current artifact is ad-hoc signed and not notarized. Follow the manual trust step only if you intend to run this build.

Disclosure: RC local only. Public distribution remains blocked until an approved trust path is chosen and verified. Do not disable Gatekeeper globally.

Before installing

FFideo 1.0.0 requires macOS 13 or later and Apple Silicon. Verify SHA256SUMS from the release directory before opening the app.

Install

  1. Verify SHA256SUMS from the release directory.
  2. Extract FFideo-1.0.0.zip.
  3. Move FFideo.app to /Applications or another folder owned by the current user.
  4. Launch FFideo.

Enable Open at Login only after moving FFideo to its final location. This ad-hoc build uses a per-user LaunchAgent fallback when macOS does not expose the main app through SMAppService; if the app is moved later, launch it manually once so Launch Services sees its new location.

For a future non-notarized private beta, macOS may require an explicit owner-approved exception through System Settings → Privacy & Security → Open Anyway. Do not disable Gatekeeper globally.

Uninstall

  1. Quit FFideo and wait for any active conversion to finish or cancel.
  2. Delete FFideo.app from its installation location.
  3. Empty Trash if desired.

FFideo does not install system services, kernel extensions, privileged helpers, browser extensions, or background daemons.

A future activated build may keep trial or license state in the user's secure/local application storage. The final public uninstaller documentation must name the exact storage identifiers after the production license integration is approved. Deactivating this Mac before deletion is recommended when that feature is enabled.

Converted media files are user documents and are never removed by uninstalling the app.
